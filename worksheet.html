Printable decoding worksheet

Generate a set of surface-code decoding puzzles for a classroom. Each question shows an injected error and a named decoder; students predict whether the code is fixed or an error gets through. Every answer is the real outcome computed by the same evaluateCorrection the interactive tool uses. Set your options, then use your browser's Print (Ctrl/Cmd+P) to save a PDF, the answer key is on the last page.

Tip: the worksheet and its answer key are fully deterministic from the seed above, so every student who uses seed classroom-1 gets the identical sheet. Change the seed to make a fresh set; keep it to reprint the same one.
